## 🌟 Unique Architectural Features

- **🧠 Interactive RAG Simulator ("AI Lab")**: A live simulated Retrieval-Augmented Generation pipeline demonstrating dense vector embeddings, ChromaDB cosine similarity search, chunk retrieval, and grounded LLM text generation.
- **⚡ Cyber Terminal OS ("Saeed OS")**: An interactive in-browser CLI (`help`, `skills`, `projects`, `rag`, `matrix`, `contact`, `sudo hire`) with audio feedback.
- **🌌 Dynamic Neural Constellation Background**: Physics-based HTML5 canvas particle network reacting smoothly to mouse motion.
- **🎵 Zero-Dependency Web Audio Synthesizer**: Custom sci-fi haptic sound effects generated via browser `AudioContext` with an interactive sound toggle.
- **🌐 Full Bilingual Support (Persian & English)**: Native RTL & LTR styling, typography optimized with `Vazirmatn`, `Space Grotesk`, and `JetBrains Mono`.
- **✨ 3D Holographic Card & Scanline Effects**: Perspective parallax tilt and real-time matrix rain toggle.

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/saeedaliakbari4j/saeed-portfolio.git

# Navigate to project
cd saeed-portfolio

# Install dependencies
npm install

# Run local development server
npm run dev

# Build production bundle
npm run build
```
